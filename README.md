# Scholarship Web

Local learning platform for Scholarship — courses, cart, and checkout.

## Features

- Full course catalog (83+ programs)
- Add to cart, Buy now, Checkout, Place order
- Orders stored in browser `localStorage` — **no external redirects**
- Dark green glassmorphism hero + animated marquee / reveal effects
- Featured visual at `/images/scholarship-hero.jpg`

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview production build
